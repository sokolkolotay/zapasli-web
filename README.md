# Zapasli Web

Продуктовый сайт Zapasli: семейного Android-приложения для учёта домашних
продуктов, сроков годности и планирования питания.

Сайт реализован как статическая страница без обязательного JavaScript и без
runtime-зависимостей. Визуальный ритм вдохновлён редакционной подачей сайта
Niagara Launcher, но тексты, композиция, интерфейсный mockup, палитра и
изображение созданы специально для Zapasli.

Hero-блок содержит анимированный mockup с тремя экранами приложения. Движение
автоматически отключается при системной настройке reduced motion. Кнопка
«Скачать приложение» ведёт на проверенный demo APK из GitHub prerelease
[`v0.3.0-auth`](https://github.com/sokolkolotay/zapasli-android/releases/tag/v0.3.0-auth).

Анимированный mockup повторяет три реально доступных экрана Android-релиза:
кладовую, карточку продукта и настройки. Будущие функции явно отделены в
разделе roadmap.

## Требования

- любой статический HTTP-сервер;
- современный браузер с поддержкой CSS Grid.
